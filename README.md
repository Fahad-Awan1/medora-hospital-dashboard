# Medora — Hospital Management Dashboard

An interactive hospital management dashboard, designed and developed by **Malik Fahad Awan**.

> **Portfolio case study.** This dashboard was built for a private healthcare client. The client's name and real data are confidential, so this public version runs entirely on **dummy data**. The design, screens and interactions match the product delivered to the client.

## Screens

| Screen | What it shows |
|---|---|
| **Dashboard** | Patient admissions by department, patient sources, bed occupancy, today's revenue |
| **Analytics** | Length of stay, readmissions, satisfaction, admissions vs discharges, gender and age breakdown, top diagnoses |
| **Billing** | Monthly revenue (PKR), insurance claims, invoices with mark-as-paid, outstanding dues, payment methods |
| **Pharmacy** | Stock KPIs, dispensing activity, expiry alerts, medicine inventory with reorder, stock by category |
| **Calendar** | Monthly calendar, doctors on duty, weekly schedule with booking, completion and cancellation |

## Features

- Every button is functional: filters, search, dropdowns, detail views, forms with validation, undo actions
- Export any screen to CSV, or print / save as PDF
- Compact and focus layouts, reduced-motion setting, live revenue ticker
- Animated charts built from scratch with SVG and CSS (no chart library)
- Responsive down to phone width

## Tech

Plain HTML, CSS and JavaScript — no framework and no build step.

## Run locally

Open `index.html` in a browser.
